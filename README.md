# BookStore App - Online Bookstore Management System

Aplikasi Web **BookStore** yang dibangun untuk memenuhi Tugas Praktik Demonstrasi (**FR.IA.02**) Skema Sertifikasi **Pengembang Web Pratama (Junior Web Developer)** dengan nomor skema `020403`.

---

## Unit Kompetensi SKKNI yang Diimplementasikan

| Kode Unit | Judul Unit Kompetensi | Implementasi pada Proyek |
| :--- | :--- | :--- |
| **J.620100.005.02** | Mengimplementasikan *user interface* | Desain antarmuka responsif menggunakan Blade & Tailwind CSS/Bootstrap |
| **J.620100.010.01** | Menerapkan perintah eksekusi pemrograman berbasis teks, grafik, & multimedia | Pengolahan teks, render gambar cover buku, dan komponen interaktif |
| **J.620100.015.01** | Menyusun fungsi, file atau sumber daya pemrograman yang rapi | Struktur arsitektur MVC (Model-View-Controller) yang tersusun rapi |
| **J.620100.016.01** | Menulis kode sesuai *guidelines* dan *best practices* | Penulisan DocBlock comment, penamaan variabel deskriptif, dan *clean code* |
| **J.620100.017.02** | Mengimplementasikan pemrograman terstruktur | Penggunaan kontrol alur, perulangan, dan modularisasi fungsi |
| **J.620100.019.02** | Menggunakan *library* atau komponen *pre-existing* | Integrasi paket Laravel, SweetAlert2, FontAwesome, dan UI Components |

Proyek ini dikembangkan oleh saya **Wahyu Andika Rahadi** sebagai bagian dari Uji Kompetensi Keahlian (USK) skema **Pengembang Web Pratama (Junior Web Developer)** dengan nomor skema **020403**, yang menghadirkan aplikasi web **BookStore** berbasis Laravel untuk memfasilitasi manajemen katalog, kategori, daftar pengguna, dan pemantauan pesanan bagi **Admin**, serta fitur registrasi, pencarian buku, halaman *About Us*, kontak, keranjang belanja, hingga transaksi *Payment at Delivery* bagi **User**.
